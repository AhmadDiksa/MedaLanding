              Questions

              Good to know

              What does a project include?

              Requirements, infrastructure, design and scope, coding, user acceptance testing and production. You see each stage, from the first conversation to launch.

              How much does custom software cost?

              It depends on scope: users and roles, features, integrations, platforms and data migration. After requirements we agree the scope and a quote.

              How long does it take?

              It depends on scope. The timeline is agreed at the design and scope stage, before coding begins.

              Can you connect to our existing systems?

              Yes, through APIs or data import where the existing system allows it. We check this during requirements.

              Which technologies do you use?

              Go, JavaScript and TypeScript, Next.js, PostgreSQL, SQLite, C# and Flutter. We choose by fit, not fashion.

              Custom software or a ready-made product?

              If one of our products already covers your need, we will say so. If not, we build it custom.
